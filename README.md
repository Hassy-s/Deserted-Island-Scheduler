# 無人島工房スケジューラー v1.2.0

## 手動置き換え
- 生成済みスケジュールの島産品をクリックすると、その場にコンパクトな置き換え候補を表示。
- 24時間を壊さないよう、元と同じ製作時間の島産品を候補化。
- 名前の全検索とカテゴリ絞り込みに対応。
- 初期表示は上位6件。「すべて表示」で全候補を表示。
- 候補は「あわせて生産を前後とも維持 → 片側維持 → なし」の順を優先。
- 置き換え後は青船貨目安・素材・あわせて生産・やる気・ねこみみ進捗を再計算。
- ↶ / ↷ で手動置き換えの取り消し・やり直しに対応。

## 履歴
- 「直前の確定を取り消す」に加えて「取り消しを戻す」を追加。

## 維持
- v1.1.6までの高速探索、ねこみみ最適化、79素材進行度判定、設定UIを維持。
