# 無人島工房スケジューラー v1.4.0

正式版です。

## v1.4.0 主な変更
- 生成エンジンを「パママ型の日次候補 + 週間Beam探索」へ刷新
- 24時間ぴったり・あわせて生産成立・同一島産品の1日重複なしの日次候補から週間予定を探索
- 素材使用量を週間単位で正確に管理し、素材上限をハード制約として扱う
- 素材使用目安は基本「目安+5」以内（工房数刻みに切り下げ）
  - 例：目安20・4工房なら基本上限24
- 素材上限の扱い
  - 自動緩和（おすすめ）：必要な場合のみ最大2段階まで緩和
  - 上限を厳守：基本上限を絶対に超えない
- 「価値維持ライン」を「価値の優先度」に変更
  - バランス重視（96%）
  - やや価値重視（97%）
  - 価値重視（98%）
  - かなり価値重視（99%）
  - 最高価値優先（100%）
- 設定説明文を検索設定の最下部へ集約
- 既存の「ねこみみさんのおねがい」「作りたい島産品」「使いたくない素材」「今週分を確定」「履歴」「置き換え候補」などを維持

## 起動
`index.html` をブラウザで開いてください。
