# 無人島工房スケジューラー v1.3.2

- ヘッダーに「素材の使用をできるだけ分散し、採取・補充の負担を抑えながら青船貨を稼ぐ」ツール目的を追記。
- 生成ボタン下に「各種設定」の小見出しを左寄せで追加。
- 折りたたみ記号を全設定で「＋（閉） / −（開）」に統一。
- 「制約の達成状況」を「ねこみみ達成状況」へ変更。
- ねこみみOFF時は「使用しない」、生成達成時は「✓ 達成」と表示。
- 生成アルゴリズム説明を「『作りたい制作物』の設定を優先しつつ、青船貨と素材負担のバランスが良いスケジュールを探索します。」へ変更。
- v1.3.1の「あわせて生産 ＞ 作りたい制作物」の優先ロジックを維持。
