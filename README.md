# 無人島工房スケジューラー v1.5.3

正式版です。

## v1.5.3 変更点
- 「素材の節約・除外」の上部ツールバーをコンパクト化
- 表示絞り込みを「すべて / 少なめ / 除外」の連結ボタンに変更
- 一括操作を「すべて除外 / 除外を解除」に短縮し、横幅を削減
- 「少なめ」と「除外」の排他動作、2週間負担評価、生成ロジックは v1.5.2 から変更なし

## 素材の節約・除外
- 何もチェックしない：通常使用
- 少なめ：カテゴリの素材使用目安のおよそ半分を理想として節約（必要なら超えてOK）
- 除外：使用しない
- 「少なめ」と「除外」は同時には選択できません

## 起動
`index.html` をブラウザで開いてください。
