# 無人島工房スケジューラー v1.5.9

正式版です。

## v1.5.9 変更点
- 「上限を厳守」で価値優先度設定に届かない場合でも、素材上限内で生成可能な最高価値のスケジュールを表示するよう変更
- 上記の場合のみ「今週の工房計画」のカード下に注意バーを表示
  - 通常時は要素を `hidden` にしているため、余白や高さは増えません
  - 表示文：
    「⚠ 上限厳守モードのため、価値優先度設定条件を満たしていません。代わりに、条件内で最良の価値XX.XX%のスケジュールを表示しています。」
- 8列あるスケジュール表に対してエラー・未生成行が7列結合になっていた不具合を修正
  - `colspan="7"` → `colspan="8"`
  - 「やる気」列だけ白く残る表示崩れを解消
- 素材上限そのものの計算は v1.5.8 のまま
  - 厳守：入力値をそのまま上限として使用
  - 自動緩和：入力値 +5 を基本許容上限として使用

## 起動
`index.html` をブラウザで開いてください。
