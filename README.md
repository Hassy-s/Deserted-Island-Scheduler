# 無人島工房スケジューラー v1.5.2

正式版です。

## v1.5.2 UI変更
- 素材設定を「素材の節約・除外」に整理
- 通常使用は何もチェックしない方式に変更
- 各素材の左側に「少なめ」「除外」のチェック欄を配置
- 「少なめ」と「除外」は排他制御され、同時にONにはできません
- 上部右側に「表示：すべて｜少なめのみ｜除外のみ」を追加
- 「除外をすべて解除」は除外だけを解除し、「少なめ」指定は維持します

## v1.5 系の生成ロジック
- 「少なめ」は素材カテゴリの使用目安のおよそ半分を理想とするソフト目標
- 必要なら半分を超えて使用可能
- 先週の確定履歴がある場合、最高価値から2%以内の候補で2週間の素材偏りを比較
- 履歴や「少なめ」を理由に探索失敗にはしません

`index.html` をブラウザで開いて使用します。
