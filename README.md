# 無人島工房スケジューラー v0.41

## 超軽量化
候補数を単純に削るだけでなく、探索処理そのものを見直しました。

- 検索モード・素材上限・週履歴を生成開始時に1回だけ取得
- 「あわせて生産」が成立可能なら、素材条件を守れる範囲で成立候補を中心に探索
- 素材負担を各探索状態にキャッシュし、同じ値を何度も再計算しない
- 週間素材負担も状態に保持
- あまりヒットしない重い日単位キャッシュを廃止
- あわせて生産の事前判定をIDセット化
- 似た候補を早期に枝刈り
- 素材上限超過ペナルティが最終評価にも反映されるよう整理

## 表示
- あわせて生産成立行を薄い緑色で表示
- 「あわせて生産」バッジを表示
