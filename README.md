# 無人島工房スケジューラー v1.6.0 RC1

正式版前の動作確認用 RC1 です。

## v1.6.0 RC1 変更点
- 週間探索を段階式 Pareto-lite に刷新
  - K160 / 最大400状態から開始
  - 価値優先度に未達の場合だけ K224 / 600 → K320 / 1200 と深掘り
- 各探索段階で5日分の曜日順を120通り再評価し、曜日最適化後の価値で停止判定
- 90〜98%は設定ライン到達時に早期終了
- 100%は許された探索段階・自動緩和を最後まで探索してBESTを採用
- 深い探索で一時的に結果が悪化しても、それまでに見つけたBESTを保持
- 「ねこみみさんのおねがい」「作りたい島産品」は必須条件として探索状態に保持
- 「少なめ」と先週＋今週の素材負担は、従来どおり最終候補の2%価値帯だけで比較
- 上限厳守は入力値をそのまま厳守、自動緩和は従来どおり +5 基本許容＋最大2段階
- v1.5.10 の置き換えUI、履歴、警告表示など既存UIは維持

## 起動
`index.html` をブラウザで開いてください。

## RC1について
大きな探索ロジック変更を含むため、v1.5.10を残したまま動作確認してください。
