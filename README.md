# 無人島工房スケジューラー v1.5.0

正式版です。

## v1.5.0 主な変更

### 素材ごとの「使用方針」
素材ごとに次の3段階を選べます。

- **通常**：これまで通り使用します。
- **少なめ**：その素材カテゴリの「素材使用の目安」のおよそ半分を目標にします。ただしハード上限ではなく、必要な場合は超えて使用します。
- **使わない**：その素材を使用する島産品を候補から完全に除外します。

「少なめ」は0個まで無理に減らすのではなく、目安の約半分以下になれば十分とみなします。

### 先週＋今週の2週間負担
「今週分を確定」した履歴がある場合、次回生成時は先週と今週を合わせて同じ素材へ偏りすぎない案を優先します。

- 先週の素材を今週も絶対禁止にはしません。
- 2週間合計が多くなるほど段階的に避けやすくします。
- うまく収まる案がなくても生成失敗にはしません。

### 価値低下は最大2%まで
素材の「少なめ」指定と2週間負担による最終選択は、**その素材上限条件で得られた最高価値から2%以内**の候補だけを比較します。

そのため、素材を過剰に避けるために青船貨価値を大きく落とすことはありません。既存の「価値の優先度」の最低ラインも同時に守ります。

### CPU負荷
日次候補生成・週間Beam探索の幅は増やしていません。新しい判定は、探索後に残っている候補を比較するだけです。
