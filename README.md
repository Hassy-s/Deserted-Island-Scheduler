# 無人島工房スケジューラー v1.3.1

## 作りたい制作物の優先ルール修正
- 「あわせて生産」を「作りたい制作物」より上位に固定。
- 作りたい制作物は、実際に「あわせて生産」で作れる場合だけ優先加点。
- 非効率な位置へ無理やり作りたい制作物を差し込むための加点は廃止。
- 選択した制作物とカテゴリが繋がる前置き品を軽く優先し、
  「前置き品 → 作りたい制作物」の順を逆算して組みやすくしました。
- 週評価でも、作りたい制作物が「あわせて生産」で作られた場合のみ軽く評価。
- 同じ作りたい制作物を何度作っても加点が増え続けないよう、品目ごとに週1回分だけ評価。

## 優先順位
1. ねこみみさんのおねがい（有効時は必須）
2. あわせて生産
3. 作りたい制作物を「あわせて生産」で組み込む
4. 青船貨と素材負担のバランス

## UI
- 「作りたい制作物」は折りたたみ表示を維持。
- v1.3.0の配置・説明文・ヘッダー改善を維持。
