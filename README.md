### 素材使用の目安
設定した数値を目安に、素材の使用量が偏りすぎないよう調整します。

- 自動緩和：条件を満たせない場合のみ、素材使用量の許容範囲を少し広げます。
- 上限を厳守：許容範囲を広げずに生成します。

素材カードでは使用数だけを表示し、内部上限の数値は表示しません。
上限付近の素材は色で判別できます。

### 生成方式
- 24時間の有効な日次候補を作成
- あわせて生産が成立する候補を優先
- 同じ島産品を1日の中で重複させない
- 週間Beam探索で、素材使用量を正確に管理しながら5日分を選択
