# 無人島工房スケジューラー v1.5.8

正式版です。

## v1.5.8 変更点
- 素材上限を工房数に合わせて丸める処理を廃止
- 「上限を厳守」は入力した数値をそのまま上限として探索します
  - 例：30なら上限30のまま判定し、31以上の候補を除外します
- 「自動緩和」は入力値 +5 を基本の許容上限として使用します
  - 例：30なら基本上限35
- 実際の素材使用数が工房数の倍数になることは、生産結果として自然に反映されます
- 生成アルゴリズム、2週間素材負担、「少なめ / 除外」、概算獲得数は v1.5.7 から変更なし

## 起動
`index.html` をブラウザで開いてください。
