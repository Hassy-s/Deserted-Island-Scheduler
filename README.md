# 無人島工房スケジューラー v1.5.0

## 正式実装
C方式の日ごと探索を正式採用しました。

- やる気40未満では、各日の先頭1枠のみ4H
- その後は4H / 6H / 8Hを自由探索
- 「標準 / 最高効率」を廃止し、「価値維持ライン」95〜100%に変更
- 初期値は96%（おすすめ）
- 数値を上げるほど価値を優先し、素材が偏りやすくなります
- 素材使用目安+5までは無罰
- +6〜+10は通常ペナルティ
- +11以上は強ペナルティ
- ねこみみさんのおねがいは有効時必達
- 作りたい島産品、除外素材、進行度、工房グレード、置き換え、週間確定・8週履歴保存を維持
- 概算青船貨獲得数は需要・人気度補正1.3倍を維持

### 価値維持ライン
その日の最高価値を100%として、指定した割合以上の候補から素材負担の軽い案を選びます。
