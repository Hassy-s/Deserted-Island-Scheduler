# 無人島工房スケジューラー v1.1.2

## ねこみみさんのおねがい配置改善
- 原則、お願い品は3〜5日目に配置します。
- 3〜5日目の72時間だけで達成可能かを、あわせて生産なしの保守的な条件で事前判定します。
- 後半だけで達成可能なら、1〜2日目はお願い品を候補から外し、やる気育成に専念します。
- 後半だけでは物理的に不足する場合のみ、お願い品を1〜2日目へ前倒しできます。
- 3〜5日目では未達のお願い品は素材使用目安（ソフト上限）や候補数枝刈りで消えません。
- 明示的な素材除外・進行度制限は従来通り厳守します。
