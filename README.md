# 無人島工房スケジューラー v1.3.7

## 工房グレード対応
- 81種すべての島産品マスターを「工房I」の基本取引額へ統一。
- 開拓ランクから工房グレードを自動判定し、アップグレード済みとして計算。
  - Rank 3–5: 工房I
  - Rank 6–7: 工房II（+10%）
  - Rank 8–13: 工房III（+20%）
  - Rank 14–18: 工房IV（+30%）
  - Rank 19–20: 工房V（+40%）
- 置き換え候補の表示を「基本価値」からゲーム内表記の「基本取引額」へ変更。
- 生成時の価値評価、各枠の価値目安、週間概算にも現在の工房グレードを反映。
- 工房補正→やる気補正の順で端数を切り捨てる計算へ調整。
- 既存の素材分散、ねこみみ、作りたい島産品、置き換え判定などは維持。
