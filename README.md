# 無人島工房スケジューラー v1.1.3

## ねこみみさんのおねがい修正
- v1.1 のクリーン版から再構築。
- お願い品は原則3〜5日目へ配置。
- 3〜5日目の72時間で達成可能かを「あわせて生産なし」で保守的に判定。
- 後半だけで足りる場合、1〜2日目はお願い品を外してやる気育成に専念。
- 後半だけで足りない場合のみ1〜2日目への前倒しを許可。
- 3〜5日目の未達お願い品は、素材ソフト上限・候補数枝刈りで消さない。
- 明示的な素材除外と素材進行度制限は従来どおり厳守。
- 高速探索・79素材進行度マスターを維持。
