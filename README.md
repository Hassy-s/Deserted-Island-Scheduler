# 無人島工房スケジューラー v1.4.1 C統合テスト

v1.3.8 を土台に、生成エンジンだけを日ごと探索の C 方式へ差し替えた統合テスト版です。

- やる気40未満：各日の先頭1枠のみ4H固定
- その後：4H / 6H / 8H 自由探索
- 標準モード：各日の最高価値95%以上を確保した候補から素材分散
- 素材設定値+5まで無罰
- +6〜+10：通常ペナルティ
- +11以上：強ペナルティ
- ねこみみさんのおねがい：残り日数で達成可能な候補を維持し、最終的に必達
- 作りたい島産品・週間確定履歴・LocalStorage・置き換え候補など既存機能を維持

正式版ではなく動作確認用です。
