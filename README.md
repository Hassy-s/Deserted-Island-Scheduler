# 無人島 開拓工房スケジュール v1.6.0 RC2

ブラウザだけで動くFFXIV無人島・開拓工房スケジュール生成ツールです。

## RC2
- 90〜98%: 段階式 Pareto-lite
- 100%: Fast 3探索
- Lazy State / Requirement Cache / Incremental Bucket
- 長い生成では日ごとにブラウザへ制御を返し、進捗・経過時間を表示
- 100%自動緩和は生成後の実素材量から必要最小の緩和段階を再判定
- 100%の「少なめ」・履歴は最高価値を落とさない候補だけで使用

`index.html` を開くだけで使用できます。設定・履歴はブラウザの LocalStorage に保存されます。
