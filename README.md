# 無人島工房スケジューラー v1.1

## v1.1 進行度対応
- 79素材すべてに実際の入手進行度を設定
- 開拓ランクだけでなく、必要素材がその時点で入手可能かを生成候補に反映
- ねこみみさんのおねがい候補も同じ進行度判定を使用
- 「使いたくない素材」も現在入手可能な素材だけを表示
- 作物・飼育動物・採集・グラナリーの分類を素材マスターに一本化
- ミスリルピックはゲーム内確認済みの Rank 17 を採用
- 各ランクで作成可能な開拓道具・必須進行イベントは完了済みの前提
